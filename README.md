  <h1>🚦 UESW</h1>
  <h3> User Enabled Safety Web </h3>
  <a>서울 중심의 실시간 교통안전 정보 제공 및 사용자 참여 기반 웹 플랫폼</a>
</div>
<div>
  <h2>📌주요 기능 및 특징</h2>
  <ul>
    <li>🚥 <strong>교통안전</strong>: 실시간 돌발사고 정보 확인, 수도권 내 공중화장실 및 공영주차장 위치 안내, 실시간 대중교통 정보 제공</li>
    <li>🚙 <strong>교통정보</strong>: 서울 지역 날씨 예보, 실시간 교통뉴스 제공, 주제별 교통사고 통계 시각화(차트), 실시간 수도권 CCTV 영상 제공</li>
    <li>🗒️ <strong>게시판</strong>: 실시간 채팅 기반 소통 게시판, 건의 게시판 글 작성 및 대댓글 포함 댓글 기능 제공</li>
    <li>📰 <strong>회원정보</strong>: 이메일/소셜 로그인 지원, 마이페이지를 통한 개인정보 조회 및 수정 기능 제공</li>
  </ul>
</div>
<div>
  <h2>⚒️사용 기술 및 언어</h2>
  <ul>
    <li>SpringBoot: JDK17, WAR, Maven</li>
    <li>Python: Flask, Pandas</li>
    <li>HTML: ThymeLeaf</li>
    <li>CSS: BootStrap</li>
    <li>JS(ES6): Chart.js</li>
  </ul>
